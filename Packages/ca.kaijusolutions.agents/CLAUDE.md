# Working with Kaiju Agents

Kaiju Agents supports Unity 6.7 beta and Unity 7 alpha. Start with Documentation~/index.md or open Documentation~/index.html directly in a browser. In an installed package locate these beside package.json using Package Manager's Show in Explorer or Reveal in Finder.

Use a KaijuTransformAgent, KaijuRigidbodyAgent, KaijuCharacterAgent or KaijuNavigationAgent for GameObject-based gameplay. The default Entities world registers enabled agents. Agent creation, pooling and identifier lookups work without a scene manager. Use the movement and controller guides for the event order and supported steering behaviours.

Use Tools > Kaiju Solutions > Agents > Install Agent Skills to install this package's skills in the consuming project. The Unity CLI exposes the same operation through the kaiju-agents command group.
